## 🔑 Key Concepts Explained

### TAD (Technical Architecture Document)
- What it is: Documentation of technical architecture and design decisions
- How detected: Keyword search in JIRA issues (PR names or description)
- Keywords: TAD, TECHNICAL ARCHITECTURE, TECHNICAL DESIGN, ADR
- See: [backend/api-gateway/TAD_TS_README.md](backend/api-gateway/TAD_TS_README.md)

### TS (Test Strategy)
- What it is: Documentation of testing approach and strategy
- How detected: Keyword search in JIRA issues (PR names or description)
- Keywords: TS FOR, TEST STRATEGY, TEST PLAN, TESTING STRATEGY, QA STRATEGY
- Exclusion: "TS FILE" (to prevent false positives)
- See: [backend/api-gateway/TAD_TS_README.md](backend/api-gateway/TAD_TS_README.md)

### Compliance Score
- TAD %: Percentage of issues with TAD documentation
- TS %: Percentage of issues with TS documentation
- Both %: Percentage of issues with both TAD and TS
- See: [TAD_TS_INTEGRATION_PLAN.md](TAD_TS_INTEGRATION_PLAN.md)

## 🚀 Quick Setup (5 minutes)

For the impatient developer:

```bash
# 1. Install dependencies
cd backend/api-gateway
npm install

# 2. Get JIRA token from https://jira.wolterskluwer.io/secure/ViewProfile.jspa

# 3. Edit .env file
notepad .env
# Add: JIRA_API_TOKEN=your_token_here

# 4. Start SQL Server (Docker recommended)
# See: SQL_SERVER_SETUP.md

# 5. Run server
npm start

# 6. Test it
curl http://localhost:3000/health
curl http://localhost:3000/api/tadts/compliance
```

See [backend/api-gateway/QUICK_REFERENCE.md](backend/api-gateway/QUICK_REFERENCE.md) for more commands.
